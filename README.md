# Nexora Technologies website

Static multi-page website built for GitHub Pages. No build step or server-side code is required.

## Pages
- `index.html` — Home
- `services.html` — Services
- `work.html` — Selected work
- `project-good-luck.html` — Good Luck Computers case study
- `about.html` — Studio and founder
- `contact.html` — Direct contact

## Deploy to GitHub Pages
1. Extract this folder locally.
2. In `taufik-develops/portfolio`, choose **Add file → Upload files**.
3. Upload the six HTML files and the complete `assets` folder, preserving the folder structure.
4. Commit the changes to `main`.
5. In Settings → Pages, choose **Deploy from a branch**, `main`, and `/ (root)`.
6. The free site address should be `https://taufik-develops.github.io/portfolio/` once Pages finishes publishing.

The older `portfolio.html` file is not required by the new site and may be kept as a backup.
